# Basu--Karisani source pins

The adjacent versioned PDFs are the primary algorithmic sources for the D3
global semialgebraic diagram replacement gate:

- `arxiv-2009.13365v3.pdf`, *Efficient simplicial replacement of
  semi-algebraic sets*;
- `arxiv-2207.10497v1.pdf`, *Computing the homology functor on
  semi-algebraic maps and diagrams*.

Their byte lengths and SHA-256 digests are recorded in the cycle's
`LITERATURE_MANIFEST.json` and `OPENING_STATE.json`.  Pinning a paper is not
an implementation or theorem certificate.
