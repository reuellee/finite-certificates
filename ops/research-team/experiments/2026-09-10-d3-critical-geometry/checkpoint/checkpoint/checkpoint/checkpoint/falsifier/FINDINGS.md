# Falsifier result: full witness fibers do not make the tangent injectivity map injective

**An exact model obtained by linearizing the five active normals of the latest actual parent has a noninjective pair map. This is a linearized transverse model, not an actual 9DVL counterexample. No original obligation is discharged or refuted.**

The bounded check tests 32 relative sign patterns. Eight have a two-dimensional full-support positive kernel cone, four have only a kernel ray, and twenty have no nonzero nonnegative kernel. We compute the entire planar compact-support restriction diagram for all 56 triples among the eight full-support patterns. Forty-eight diagrams have a one-dimensional kernel; eight have zero-dimensional source. All 56 triple cones have a nonempty link and hence are connected and noncompact. The four boundary-only patterns are not included in this 56-case cohort.

For a relative sign pattern `s in {+1,-1}^5`, consider the *linearized affine feasibility problem*

`there exists v in R^3 with s_i(A_i v + h_i) > 0 for all five i`.

Set `u=K^T h`. The nonnegative kernel cone is parameterized by

`C_s={q in R^2 : s_i (Kq)_i >= 0 for every i}`.

Strict affine Farkas duality gives the exact equivalence

`GOOD_s <=> q dot u > 0 for every nonzero q in C_s`.

For a full-dimensional pointed `C_s`, it suffices to test its two extreme rays. Therefore `BAD_s` is exactly the union of the two closed halfplanes where an extreme-ray evaluation is nonpositive. This calculation retains every nonnegative witness, including boundary rays and zero weights; it chooses no section.

The two previously certified parent perturbations H and G give first derivatives

`h(alpha,beta)=alpha*(0,-2,2,2,-2)+beta*(1,1,1,1,1)`.

The map from `(alpha,beta)` to `u` is

```
[ 6/25,      267/25
 -257/100,   2347/200 ],
```

with nonzero determinant. Thus the complete parameter plane of the stated *linearized* model is reached by actual first-order parent directions. This does not show that the nonlinear parent loci are globally or locally homeomorphic to this plane model.

## Compact-support computation

Intersect each closed cone with a circle represented by eight cyclic vertices and eight edges. The vertices are the primitive signed rays of the rows of K; repeated rays are merged. An extreme evaluation has constant sign on each open edge, so exact rational midpoint tests compute the entire closed link subcomplex, including endpoints.

For any nonempty closed planar cone C in this model, its compactification is the suspension of its link. In degree one this gives the natural identification

`Hc^1(C;Q) = reduced H^0(link(C);Q)`.

The code computes connected link components and the actual restriction of component indicator functions modulo constants. It assembles `D=(r01,-r02,r12)` using these bases, then computes exact rational ranks and nullspaces. No rank is inferred from mere witness-fiber contractibility.

A small example uses relative sign patterns

```
s0 = (-,-,-,-,-)
s1 = (-,-,-,-,+)
s2 = (+,+,+,+,-).
```

In the certificate's component bases, the pair dimensions are `(0,1,1)`, the triple dimension is 1, and

`D = [1 1]`, with kernel generated by `(-1,1)`.

Both nonzero individual restriction maps are isomorphisms. Their contributions cancel jointly. These three GOOD cones are nonempty, proper, and pairwise incomparable within this linearized model.

A homogeneous Gordan formulation adds the constraint `x4>0` to the five rows `(s_i A_i,s_i h_i)`. Normalized nonnegative infeasibility witnesses then form compact convex fibers, and the projection from their entire graph is proper. The same holds for the fiber products associated with pair and triple bad loci. Proper acyclic comparison preserves the displayed kernel; passing to the full witness graph cannot eliminate it.

## Scope limits and smallest next discriminator

This is neither an original parent-space counterexample nor an original antichain certification. There is no proof here that all 56 original inequalities have exactly the stated nonlinear germ, that the two-parameter slice is a globally proper model, or that its compact-support degree survives the other parent directions. In particular, taking the displayed cones times R^7 shifts their compact-support cohomology by seven degrees and eliminates their degree-one groups. A transverse planar kernel is not an original Hc1 class.

The result rejects any proposed argument saying that full compact convex fibers, a valid first-order compound-normal origin, or locally contractible pieces by themselves imply injectivity. It does not reject a construction that uses proper parent motions to remove these local classes or proves a global comparison respecting the other dimensions.

The smallest discriminator is now specific: for the five labeled support triples `[012,345,036,246,147]` at this parent and the displayed three relative signs, determine the semialgebraic attachment of the `rank(five derived normals)=3` stratum to the adjacent rank-four strata. First establish a neighborhood comparison for the displayed two-dimensional kernel system with its tangential parent stratum, or exhibit an additional active support that changes it. If a product comparison is valid, deciding whether that tangential stratum has a compact component decides whether the local degree-one kernel can survive that product's compact-support degree one. This is one concrete factor intersection and one explicit kernel, not a request for an unspecified global atlas. Even a positive result would address only this configuration.
