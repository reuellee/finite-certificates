## Result and classification

**Finite exact negative for a narrow D9 structural mechanism.** For the
source row-2599 charts 37 and 176, place both configurations in the same
oriented first-five-ray projective frame. Of the 512 configurations formed
by independently taking each of the nine remaining normalized coordinates
from one endpoint or the other, **only the two endpoints retain the parent
chirotope**. The analogous eight whole-nonframe-column hybrids likewise have
only two valid vertices. Consequently no path whose vertices are these
hybrids and whose steps replace one endpoint coordinate or one endpoint
column stays in the parent realization cell, even with backtracking.

This rejects endpoint-only coordinate/column replacement as a universal
connection mechanism. It does **not** reject continuous coordinate paths with
arbitrary intermediate values, adaptive frames, witness motion, or general
semialgebraic paths. In fact the inherited source already proves that these
same endpoints are connected inside the common feasibility locus of a proper
incomparable nine-family by **22,811 exact homogeneous-column segments**.
The new obstruction and that positive path are consistent: the latter is
allowed to introduce intermediate values.

No diagonal, global obligation, or exhaustive residual denominator changed.
The theorem ledger remains **2/9**. This discovery result is pending the
cycle referee's independent arithmetic and scope review. It is not a D9 or
9DVL counterexample.

## Executed test and exact deduction

The initial test used the 2^3 whole-column hybrids. Its only valid vertices
were masks `0` and `7`. The one permitted follow-through enlarged the finite
vertex set to all 2^9 scalar-coordinate hybrids. Its only valid vertices
were masks `0` and `511`. Both endpoint vertices are isolated, so monotone
replacement orders and arbitrary backtracking on this graph fail.

The normalization is explicit. For endpoint matrix `A`, invert its first four
columns `B`, and let `f=B^-1 A_5`. Apply
`T=diag(1/f_i) B^-1`. Positively rescale frame columns 1–4 by `abs(f_i)` and
columns 6–8 by the reciprocal absolute value of their first coordinate.
The first five oriented rays and the first coordinates of columns 6–8 then
agree exactly between the endpoints. Both transformation determinants are
strictly positive, as recorded in the output, and every column scaling is
positive. Hence parent and extension-sign conventions are preserved.

For each hybrid, the program clears denominators by **positive** column
multipliers, evaluates all 70 parent determinants as integers, and compares
with the common strict endpoint sign vector. The output records the first
wrong determinant and its expected sign for each rejected hybrid: six
whole-column records and 510 coordinate records. All nine single-coordinate
moves from the first endpoint already fail:

Bits run through rows 2,3,4 of columns 6,7,8. Because a one-coordinate or
one-column interpolation changes only one parent column, each bracket is
affine along an edge. Parent validity of both ends would therefore suffice
for parent safety on that edge. Here every first replacement endpoint already
fails, so no feasibility, wall-topology or numerical calculation is needed
to reject the finite mechanism. The test does not enumerate any full
realization-space component and does not test all permutations of projective
frames.

The endpoints' nine-family admissibility and their existing connecting path
are inherited from S10 and its exact artifacts, not re-proved by this test.
The new computation does not assert that the only *feasible realizations* are
the two endpoints: they are only the two parent-valid vertices of this fixed
512-point hybrid set. It supplies no compactification or true-infinity claim.
