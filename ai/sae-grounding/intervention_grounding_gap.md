# Abstract

Sparse-autoencoder (SAE) interventions are often treated as evidence
that a feature is causal. This note separates two claims: setting an
internal feature changes a model output, and the feature recovers a
named semantic variable together with its upstream causal relations. We
prove an exact separation. Two Markovian structural causal models with
fixed named binary concepts P and C, identical complete concept labels,
the same invertible activation X=(P,C), and the same downstream model
produce identically distributed observations and transcripts under any
adaptive protocol that retrains or intervenes only on X, SAE codes, or
their descendants. Their semantic do-distributions nevertheless differ.
The fixed concept names and labels rule out relabeling explanations; a
strictly positive four-state construction rules out off-support
explanations; a swap-symmetric witness rules out canonical
direction-selection rules; and a further construction embeds the result
at the SAE absorption wall. An exact-fraction verifier checks the joint
laws, four semantic interventions, all 4^4 deterministic post-X maps,
stochastic kernels, and an exact adaptive two-round transcript law. The
broad impossibility is standard causal non-identifiability. The
contribution is an SAE-specific intervention-grounding theorem that
clarifies which causal claims internal interventions can support.

> **NOVELTY VERDICT** This is not presented as a new general theorem in
> causal discovery. Its defensible novelty is the explicit SAE benchmark
> separation: even perfect semantic anchoring and unlimited descendant
> interventions do not substitute for interventions on the semantic
> variables themselves.

# 1. Research question and claim boundary

The research question is whether an SAE feature ontology can be promoted
from an observational or mechanistic description to a causal semantic
ontology using only interventions inside the represented model. The
answer is negative without an intervention-grounding assumption.

A semantic causal ontology consists here of fixed named variables, their
value spaces, a directed causal graph, and structural mechanisms. The
names P (parent concept) and C (child concept) are held fixed across
candidate models. This removes permutation and renaming ambiguities from
the result.

Throughout, the two objects compared are world-plus-network composites:
the downstream network and representation are literally shared, and the
candidate models differ only in the semantic generating process upstream
of the representation. Nothing in the note claims that two different
neural networks behave alike.

An internal causal claim asks what happens when an activation or code is
changed while the rest of the model is held fixed. A semantic causal
claim asks what would happen under surgery on the underlying concept
mechanism, with its descendants regenerated by the structural model. The
two operations coincide only if an additional intervention map has been
validated.

-   Claim established: all observation-only and post-representation
    experiments can be indistinguishable while semantic do-distributions
    differ.

-   Claim not established: SAE features never cause model behavior.
    Internal ablations can establish downstream causal relevance.

-   Claim not established: causal ontologies are never identifiable.
    Real semantic interventions, multiple environments, temporal
    information, or structural restrictions can break the equivalence.

# 2. Formal setup

## 2.1 Upstream semantics and represented model

Let S=(P,C) denote named semantic variables generated by an acyclic
Markovian SCM M. A fixed representation map phi produces an activation
X=phi(S). An SAE learner A receives observational activation samples and
a random seed and returns an encoder-decoder pair (e,d), with code
Z=e(X). A fixed downstream model maps represented or decoded states to
outputs Y.

S --phi--\> X --e--\> Z --intervene/decode--\> X' --h--\> Y'.

A post-representation protocol may inspect labels and activations,
retrain the SAE, choose interventions adaptively from previous results,
and act on X, Z, or any descendant. It may not intervene on the
structural mechanisms that generate P or C, and its internal operations
do not feed back into those upstream mechanisms.

## 2.2 Identifiability target

The semantic ontology is identifiable from a class of experiments if
equality of every experiment transcript law forces equality of the
semantic interventional distributions under fixed concept names. It is
enough to disprove identifiability by constructing two models that agree
on all allowed transcript laws but disagree on one distribution such as
Pr(C \| do(P=0)).

# 3. Post-representation indistinguishability theorem

## 3.1 Protocol and transcript model

The theorem is stated for an explicit finite protocol model; every term
below is a finite discrete object, so no measure-theoretic care beyond
finiteness is needed.

**Environment.** An environment M consists of (i) an upstream Markovian
SCM generating the semantic state S with observational law mu_M over
(S, X), where X=phi(S) for the fixed map phi, and (ii) downstream
mechanisms: fixed kernels from the represented state to codes, decoded
states, and outputs. Units are drawn i.i.d. from mu_M. Labels mean the
semantic values of a unit; activations mean its X.

**Actions.** An action a is a pair (K, m): a Markov kernel K on the
represented state space, applied at the cut X, together with a request
for m fresh units. Deterministic maps, single- or multi-code SAE edits
(any function of Z=e(X) is a function of X), activation patches,
steering rules, and decoded counterfactual settings are all special
cases of K. Executing a on a unit with semantic state s: the activation
x=phi(s) is generated by the unintervened upstream mechanisms; a
post-intervention state x' is drawn from K(. \| x); all variables
downstream of the cut are regenerated from x' using the shared
downstream kernels; the observation o returns any requested subset of
(labels s, activation x, code e(x), intervened state x', downstream
outputs). No feedback: K neither acts on nor is read by the mechanisms
generating S, so a unit's labels are unchanged by the intervention.

**Protocol.** A protocol Pi with round budget n is a tuple
(A, pi_1, ..., pi_n): an SAE learner A, a deterministic function of an
observational activation sample and a seed, and policies pi_t, each a
function of the history h\_(t-1) = (trained SAE, a_1, o_1, ...,
a\_(t-1), o\_(t-1)) and of protocol randomness, returning the round-t
action a_t. The transcript is T_Pi = (trained SAE, a_1, o_1, ..., a_n,
o_n).

## 3.2 Theorem and proof

> **THEOREM 1 (ADAPTIVE DESCENDANT-INTERVENTION EQUIVALENCE)** Let M1
> and M2 have the same observational law mu of all available labels and
> activations, and let every mechanism downstream of X be the same. Then
> every finite randomized adaptive protocol in the model of Section 3.1
> has identically distributed transcripts under M1 and M2. This remains
> true when the protocol trains or selects an SAE from the observed
> activations. Consequently, if M1 and M2 have different semantic
> do-distributions, no such protocol identifies the semantic causal
> ontology.

## Proof

Construct a coupling. On a single probability space, draw once: the
observational training sample of (S, X) pairs, the (S, X) pairs of every
fresh unit any round may request, the learner seed, the protocol
randomness, and the randomness used to realize every kernel K and every
downstream mechanism. This is legitimate because the law mu of (S, X) is
identical in M1 and M2 by hypothesis, and seeds, kernels, and downstream
mechanisms are model-independent objects. Run both experiments on this
common space.

Proceed by induction over rounds. The trained SAE is a deterministic
function of the common sample and seed, hence equal in both runs. Assume
the histories h\_(t-1) agree. Then the policy pi_t, evaluated on the
common history and common randomness, selects the same action (K, m) in
both runs. The round-t observation is a deterministic function of the
fresh units' (S, X) pairs, the kernel randomness, and the downstream
mechanisms. Of these, only the pre-intervention pair (S, X) could carry
upstream information, and it is common under the coupling; the kernel
randomness is shared by construction; the downstream mechanisms are
shared by hypothesis. In particular, a label inspected after an
intervention is the unit's unchanged semantic state, equal to
phi^(-1)(x) for the pre-intervention activation x, so post-intervention
label access supplies nothing beyond the shared law mu. Hence o_t is
equal in both runs, the histories h_t agree, and by induction the entire
transcripts are equal almost surely under the coupling. Equal random
variables have equal laws, so the transcript laws under M1 and M2
coincide. At no step is the upstream factorization of mu -- which of P,
C is a root, or any structural mechanism above X -- an input to any
computation.

The theorem includes reconstruction metrics, sparsity statistics,
supervised probes, feature labels, single- or multi-code ablations,
activation patching, steering, decoded counterfactuals, and arbitrarily
many adaptively selected internal experiments. It does not include a
world-level intervention that changes a semantic generating mechanism.

# 4. Strictly positive binary construction

## 4.1 A common labeled observational law

Take binary named concepts P,C in {0,1}. Both candidate models have the
following joint distribution. Every cell is positive, and both concepts
are fully observed and retain the same labels.

Table 1. Shared strictly positive observational distribution.

| **P** | **C** | **Pr(P,C)** | **Activation X** |
|-------|-------|-------------|------------------|
| 0     | 0     | 3/8         | (0,0)            |
| 1     | 0     | 1/4         | (1,0)            |
| 0     | 1     | 1/8         | (0,1)            |
| 1     | 1     | 1/4         | (1,1)            |

Use fixed loadings a_P=(1,0)^T and a_C=(0,1)^T, so X=P a_P + C
a_C=(P,C). The representation is therefore invertible and perfectly
semantically anchored. A two-coordinate identity code is already a
perfect representation; more generally, any SAE learner sees the same
data distribution in both models.

## 4.2 Opposite causal factorizations

The forward model M\_(P-\>C) is defined by independent exogenous
randomness:

P \~ Bernoulli(1/2), Pr(C=1 \| P=0)=1/4, Pr(C=1 \| P=1)=1/2.

The reverse model M\_(C-\>P) is likewise Markovian:

C \~ Bernoulli(3/8), Pr(P=1 \| C=0)=2/5, Pr(P=1 \| C=1)=2/3.

Multiplying either root marginal by its conditional reproduces every
entry of Table 1. Thus the models have the same named variables, values,
labels, loadings, activation support, and observational probabilities.
They differ only in structural direction and mechanisms.

## 4.3 Internal and semantic interventions separate

Let the downstream score be Y=h(X)=P+2C. An internal operation
set(X_P=p) replaces only the represented coordinate and leaves the
observed C coordinate unchanged; set(X_C=c) is analogous. A semantic
do-operation instead replaces a structural equation and regenerates
descendants.

For example, set(X_P=0) leaves C at its observational marginal
Pr(C=1)=3/8, giving E\[Y\]=3/4 in both models. By contrast, do(P=0) in
M\_(P-\>C) gives Pr(C=1)=1/4 and E\[Y\]=1/2, while the same semantic
intervention in M\_(C-\>P) leaves root C unchanged and gives E\[Y\]=3/4.
The identical internal experiment therefore agrees with one semantic
model and disagrees with the other, without revealing which ontology
generated the data. In fact the pattern is exact and structural: the
internal edit set(X_P=p) coincides with do(P=p) in the model where P is
a child (so that intervening on P does not affect its parent root C,
which keeps its marginal -- exactly what the internal edit does), namely
M\_(C-\>P), and set(X_C=c) coincides with do(C=c) in the model where C
is a child, namely M\_(P-\>C). Every internal experiment is consistent
with some semantic
ontology, so internal results cannot serve even as a partial vote for a
causal direction.

## 4.4 Exhaustive finite-state check

On the four-state activation space, every deterministic decoded
intervention can be represented as a map T:{0,1}^2 -\> {0,1}^2. For any
output state x', its probability is

Pr(T(X)=x') = sum_x 1\[T(x)=x'\] Pr(X=x).

Because Pr(X=x) is common, the pushforward distribution is common for
every T. The verifier enumerates all 4^4=256 maps exactly. Stochastic
maps follow by replacing the indicator with a common Markov kernel;
adaptive compositions follow from Theorem 1, and the verifier
additionally computes one exact adaptive two-round transcript law in
full under both models.

> **MACHINE-CHECK RESULT** Exact rational arithmetic (31 checks)
> confirms both observational factorizations, the four pairs of distinct
> semantic intervention distributions in Table 2, all 256 deterministic
> post-X maps, exact stochastic-kernel pushforwards, an exact adaptive
> two-round transcript law, the swap-symmetric witness of Section 4.5,
> and the absorption-wall corollary at two parameter points. No
> floating-point tolerance is used.

## 4.5 A symmetric witness: no canonical direction selection

A remaining objection concedes non-identifiability but claims that one
factorization is canonically preferred -- for instance by a description-
length comparison of the mechanisms, or by an independence-of-mechanisms
postulate -- so that the ambiguity could be resolved by convention.
Two replies. First, such selection rules are substantive inductive
assumptions about the world, exactly the structural restrictions that
Section 7 already lists as outside the theorem's experiment class;
invoking one changes the inference problem rather than refuting the
theorem. Second, and constructively, the objection can be defeated
wholesale. Take the swap-symmetric joint

Pr(0,0)=Pr(1,1)=3/8, Pr(0,1)=Pr(1,0)=1/8,

which is dependent, strictly positive, and invariant under exchanging
the two named coordinates. Its two factorizations are exact mirror
images: forward, P \~ Bernoulli(1/2) with Pr(C=1 \| P=0)=1/4 and
Pr(C=1 \| P=1)=3/4; reverse, C \~ Bernoulli(1/2) with Pr(P=1 \| C=0)=1/4
and Pr(P=1 \| C=1)=3/4. Any selection rule that is a function of the
observational law and labels and is equivariant under the coordinate
swap must therefore score both factorizations equally, so no such rule
selects a direction. Yet the semantic gap persists:
Pr(C=1 \| do(P=0)) = 1/4 in the forward model and 1/2 in the reverse
model. The verifier checks this witness exactly. Unlike quantities that
are defined only relative to a chosen representation, a semantic
do-distribution is operationally anchored -- a world-level intervention
separates the two models in principle -- so adopting a canonical model
by convention does not make its predictions for real semantic
interventions correct; it only hides which predictions are unsupported.

# 5. General two-variable family

The example is one member of a general family. Let pi(p,c) be any
strictly positive dependent binary joint distribution. It admits both of
the following Markovian factorizations:

P -\> C: Pr(P=p) Pr(C=c \| P=p),

C -\> P: Pr(C=c) Pr(P=p \| C=c).

The observational joint and the invertible activation X=(P,C) are the
same. Under do(P=p), the first model assigns C its conditional Pr(C \|
P=p), whereas the second assigns C its marginal Pr(C). Dependence
guarantees inequality for at least one p. The symmetric statement holds
for do(C=c). Thus the positive-support construction is not isolated or
fine-tuned.

> **COROLLARY 1 (PERFECT CODES ARE INSUFFICIENT)** Even if the SAE code
> is exactly the named semantic state S, and even if the entire labeled
> observational joint is available, interventions on that code do not
> identify whether code-setting implements semantic surgery.
> Representation identifiability and semantic causal identifiability are
> distinct problems.

# 6. Corollary at the SAE absorption wall

The construction can be embedded directly in the hierarchical
two-concept distribution used in the companion SAE-identifiability
analysis (the companion's revised Certificate C uses a support-irreducible
pair and lives in the same repository; the present corollary uses only the
shared distribution and is independent of the companion's claims). At the
exact absorption wall,
let

Pr(P=0,C=0)=1-p0-q, Pr(1,0)=p0, Pr(1,1)=q, Pr(0,1)=0.

The forward SCM sets P\~Bernoulli(p0+q), C=0 when P=0, and Pr(C=1 \|
P=1)=q/(p0+q). The reverse SCM sets C\~Bernoulli(q), P=1 when C=1, and
Pr(P=1 \| C=0)=p0/(1-q). Both generate the same activation law X=P a_P+C
a_C.

Every SAE population objective and optimum set is therefore shared. In
particular, any fixed canonical solution selected in the companion
two-atom analysis, together with all of its code ablations and patches,
is common to the two SCMs. Yet do(P=0) forces C=0 in the forward model
and leaves C\~Bernoulli(q) in the reverse model.

Pr(C=1 \| do(P=0), M\_(P-\>C))=0 != q=Pr(C=1 \| do(P=0), M\_(C-\>P)).

This corollary links the new causal separation to the existing
observational absorption result: even after a canonical-selection
convention fixes the SAE decomposition, both SCMs share that canonical
solution and all of its internal interventions, and the semantic gap
survives. The strictly positive construction in Section 4 is the primary
theorem witness; the wall example, whose support contains a zero cell
and whose mechanisms each include one deterministic equation, is
included only to show compatibility with the established SAE geometry.

# 7. Stress tests and scope

The construction was deliberately strengthened against the following
objections.

-   Relabeling: P and C keep their names, values, labels, and activation
    loadings. Only their structural equations differ.

-   Off-support behavior: the main witness gives positive probability to
    all four activation states, so internal transformations never need
    an unseen state.

-   Representation failure: X=(P,C) is invertible and already gives a
    perfect two-coordinate concept code.

-   Optimization ambiguity: the theorem does not depend on a non-unique
    SAE optimum; any fixed learner has the same input and seed law in
    both models.

-   Weak interventions: Theorem 1 allows multi-feature, stochastic,
    adaptive, and unlimited post-representation interventions, not only
    single ablations.

-   Hidden confounding: both witnesses are ordinary Markovian SCMs with
    independent exogenous noise; no latent confounder is required.

-   Canonical selection: the swap-symmetric witness of Section 4.5
    defeats every direction-selection rule that is equivariant under
    exchanging the named coordinates; non-equivariant rules are
    substantive causal assumptions, not conventions.

## Boundary conditions

The no-go statement is static and feed-forward. If an internal
intervention participates in a closed loop that physically changes and
re-observes the upstream semantic system, it is no longer merely a
descendant intervention. Likewise, randomized world-level treatments,
paired semantic counterfactuals, multiple environments with known
mechanism changes, temporal order, additive-noise asymmetries, or a
known causal graph can break the equivalence.

If a 'concept' is defined operationally to mean the activation
coordinate itself, then set(X_i=x) is its intervention by definition,
and internal causal relevance is the appropriate target. The theorem
applies when the coordinate is interpreted as recovering a semantic
variable whose counterfactuals are defined outside or upstream of the
coordinate -- which is how SAE features are in practice interpreted
whenever they are given concept names.

# 8. Relation to prior work and novelty

The causal-discovery core is familiar: a dependent two-variable
observational joint admits both edge orientations, and observational
data alone do not identify the relevant do-distributions. Modern causal
representation learning (CRL) obtains stronger identifiability by adding
latent-level interventions or structural restrictions. Von Kuegelgen et
al. prove nonparametric results from unknown perfect interventions;
Varici et al. establish recovery with hard uncoupled interventions;
Welch et al. derive partial observational identifiability under
nonlinear additive Gaussian noise and linear mixing. Those results are
the complement of this note: identifiability there is purchased with
latent- or world-level interventional variation, which is precisely what
the post-representation protocol class lacks.

The closest interpretability framework is causal abstraction (Geiger et
al. 2025; Geiger et al. 2023). Interchange interventions and distributed
alignment search validate an alignment between a network and a
hypothesized high-level causal model; the methodology is explicitly
relative to that hypothesized model. Theorem 1 is the contrapositive
boundary of the same program: no amount of internal intervention, even
adaptively chosen, selects the high-level semantic model. Sutter et al.
(2025) prove a complementary impossibility with an orthogonal lever:
when the alignment map is unconstrained and non-linear, any network can
be causally abstracted onto any algorithm. Here the lever is different
-- the alignment map is held fixed, invertible, and perfectly
semantically anchored (X=(P,C) with identity alignment), and the
ambiguity lives entirely in the upstream semantic SCM. The two results
bracket the grounding problem from opposite sides: theirs shows too much
freedom in the map trivializes abstraction; this note shows that even
zero freedom in the map leaves the semantic ontology unidentified.
Makelov, Lange, and Nanda (2023) construct an interpretability illusion
for subspace activation patching, a pitfall at the level of which
subspace encodes a feature (Level B in Table 3); Meloux et al. (2025)
show empirically that multiple distinct algorithmic interpretations can
pass the same causal-alignment tests on one network. Neither formulates
an adaptive transcript-equivalence theorem over semantic generating
processes. The steering literature's gap between controlling behavior
and encoding a concept (Wu et al. 2025; Leask et al. 2025) is the
informal counterpart of the present separation.

SAE circuit and concept-interface work uses interventions to establish
that internal features affect predictions or behaviors. That is an
important causal statement and is not contradicted here. The separation
is between that downstream statement and the stronger claim that the
feature set identifies an upstream semantic causal model.

Recent evaluation work based on targeted input attribute perturbations
and recent SAE analyses of randomized trials sit on the productive side
of the boundary: they supply world- or input-level treatment variation
rather than relying only on descendant code edits. Their assumptions may
therefore ground semantic causal claims that the theorem rules out from
internal interventions alone.

# 9. Evaluation consequences

Table 3. Four levels of evidence that should not be collapsed.

| **Level**                | **Question**                                       | **Typical evidence**                    | **What it does not establish**     |
|--------------------------|----------------------------------------------------|-----------------------------------------|------------------------------------|
| A. Alignment             | Does a code correlate with a concept?              | Labels, probes, exemplars               | Causal effect                      |
| B. Internal effect       | Does editing the code change model output?         | Ablation, patching, steering            | Semantic do-effect                 |
| C. Intervention fidelity | Does code editing emulate a semantic intervention? | Paired world/input interventions        | Entire causal graph                |
| D. Ontology              | Are semantic variables and relations identified?   | Grounded interventions plus assumptions | Unqualified transfer outside scope |

A benchmark at Level B should report an internal causal effect without
silently upgrading it to Level C or D. To cross the grounding gap, an
evaluation should validate an intervention map I_i(s) intended to
represent do(S_i=s). A necessary operational check is a commuting
relationship between real semantic interventions and internal edits:

phi(S under do(S_i=s)) approximately equals I_i(phi(S)),

together with agreement of downstream outcome distributions. This does
not by itself identify an unrestricted causal graph, but it makes the
semantic meaning of the internal intervention testable rather than
assumed.

# 10. Falsifiable next steps

-   Formal extension: characterize the maximal feedback or recurrent
    setting in which internal interventions remain descendants of the
    semantic variables.

-   Positive theorem: derive minimal paired interventions sufficient to
    validate an SAE intervention map for a restricted causal abstraction
    class.

-   Empirical benchmark: build paired prompts or images that alter one
    verified semantic variable and test whether code-setting predicts
    the full response distribution, not only a logit change.

-   Literature challenge: search explicitly for prior theorems equating
    internal representation interventions with latent-variable
    interventions; either locate the missing assumptions or exhibit a
    countermodel.

The most promising path to a stronger result is therefore not a broader
impossibility statement. It is a sharp positive characterization of the
extra evidence that turns a causally relevant SAE code into a valid
semantic intervention interface.

# 11. Limitations

The exact witness contains two binary concepts and a deterministic
activation map. The adaptive theorem is architecture-agnostic but
assumes that allowed interventions do not modify upstream semantic
mechanisms. The note provides no trained-model experiment, no
finite-sample bound, and no claim that a particular published SAE study
commits the inference error isolated here. It also does not establish
that the SAE-specific formulation is publication-novel; the literature
audit supports only a conservative positioning.

# 12. Conclusion

A feature can be perfectly labeled, invertibly encoded, and causally
effective inside a model without identifying the causal semantics of the
concept it represents. The missing object is an intervention-grounding
map. Internal ablations, patches, and steering experiments test the
model's downstream mechanisms; semantic do-claims additionally require
evidence about how those edits correspond to interventions on the
semantic generating system.

For SAE identifiability research, this creates a clean hierarchy:
geometric identifiability, code identifiability, downstream causal
relevance, intervention fidelity, and semantic causal-ontology
identifiability. None of the earlier levels should be assumed to imply
the later ones without an explicit theorem or experiment.
