# The SAE feature-absorption metric is not identifying

Three exact results about the first-letter "feature absorption" score used by
SAEBench-style evaluations of sparse autoencoders. **28 exact checks, all passing**;
python3 + stdlib, sympy only where an irrational appears. No floating point in any
load-bearing step.

The metric is re-implemented line-for-line from the reference scorer
(`analysis/round13a_family_endpoint.py` in the sibling `sae-identifiability` repo), so
these are results about the code that produced published-style numbers, not about a
paraphrase of it.

## 1. It scores a zero-absorption dictionary as up to 70% absorbed

`splitting_inflation.md` — `verify_splitting_inflation.py` (17 checks)

When a letter's tokens are generated by *k* genuinely distinct features, the faithful
dictionary (one atom per feature) has zero absorption by construction, yet the metric
reports `rate_single = 1 - N_1/N`. The maximum over all zero-absorption configurations
is exactly **1 − τ** and is *attained*, not approached, because the scoring guard
`sel_j ≥ τ` is non-strict. At the registered τ = 0.30 that is **0.70**.

The family-corrected endpoint repairs this **iff** every split group clears τ, and
repairs *nothing* when none do. And the faithful dictionary is *loss-optimal* — merging
is strictly worse for every 0 < λ < 2 — so the metric penalises the correct answer.

## 2. It cannot tell single-parent from distributed absorption

`indistinguishability.md` — `verify_indistinguishability.py` (14 checks)

Two generative models — one child absorbed into ONE composite, versus *k* children
absorbed into *k* composites — each with its own loss-optimal dictionary, on which the
metric returns identical values. Not just two matching rates: the **entire per-token
observable the metric consumes** (F_L firing pattern, present, retained) is identical,
so every statistic measurable from it agrees.

Sharp: at k/N_L = τ the composite enters F_L and `rate_family` diverges, while
`rate_single` stays blind. **Repair:** a statistic reading outside F_L separates them —
modal-carrier share 1 versus 1/k. That is exactly the carrier check already run on real
Pythia-1.4B SAEs, where it answers *distributed* (14.1% against a 34.0% null).

## 3. The optimality gate

`verify_m1_optimality.py` (14 checks)

Both dictionaries are loss-optimal for their own data, which is what stops the
construction being two hand-picked dictionaries. Nonnegative lasso solved by KKT
active-set enumeration, so every number is a closed form. The tilt hazard — that ε\* is
a pure-strategy rather than a global boundary — is excluded, and ε = 0 turns out not to
be a restriction: it is the correct model for first-letter absorption (a token like
*short* cannot occur without starting with s), and for ε > 0 one extra atom restores
optimality at any ε.
